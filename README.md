# Pagina_distrisur-

Este repositorio ya es público y está configurado para publicar la app de Vite + React en GitHub Pages con GitHub Actions.

## Despliegue en GitHub Pages

1. Ve a **Settings > Pages** del repositorio.
2. En **Build and deployment**, selecciona **Source: GitHub Actions**.
3. Haz push a `main` (o ejecuta manualmente el workflow **Deploy to GitHub Pages**).

El workflow construye la app con Vite y publica `dist` en el entorno `github-pages`.
